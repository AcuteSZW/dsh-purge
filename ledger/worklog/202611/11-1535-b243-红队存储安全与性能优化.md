- `lib/redteam/store-core.js`：`deletePoc` 使用 `relative` 路径边界；`addShot` 同名文件写入前查 SQLite 并以 `wx` 独占创建；分页复用 `lib/redteam/pagination.js`；`#representativeShots` 维护有序 top-3。
- `lib/redteam/tools.js`：工具入口复用 limit 归一化。
- `scripts/selftest.mjs`：覆盖分页边界、截图重名保护、POC sibling 前缀目录保留、悬空链接和路径穿越。
- `scripts/bench-representative-shots.mjs`：固定 seed 对照算法并跑 25 轮微基准；Node v26.13.0 下典型数据中位数 10.47→3.66 ms，尾部数据 195.71→37.48 ms。此为合成内存微基准，不代表 SQLite/`scoreReport` 全链路性能。
- 验证：`npm run selftest` 全通过；相关 JS 文件 `node --check` 通过；`git diff --check` 通过。未创建 commit。
